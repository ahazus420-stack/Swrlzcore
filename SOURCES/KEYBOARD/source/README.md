# SWRLZ Keyboard IME Source

Standalone minimal Android Input Method Editor source for checkpoint `KEYBOARD-IMP-011A`.

## Identity

- namespace: `com.swrlz.keyboard.app`
- applicationId: `com.swrlz.keyboard.app`
- versionCode: `1`
- versionName: `0.1.0`
- surfaceType: `keyboard`

## Implemented scope

- ordinary offline character typing;
- space, backspace, and enter;
- Android IME service declaration and metadata;
- setup activity for Android keyboard settings and picker;
- pure protected-editor classification seam;
- no network, CLIENT, NODE_HOST, mission, clipboard-history, voice, telemetry, or AI behavior.

This source is intentionally independent from the Core app shell. It uses compatible toolchain settings without inheriting Core package identity, activity, label, manifest role, or removed demonstration modules.

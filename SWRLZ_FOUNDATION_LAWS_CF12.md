SWRLZ Foundation Laws (CF12 Draft)

Purpose
This document defines the enduring engineering principles of SWRLZ.

Core Laws
- Build foundations before towers.
- Integrate, do not overwrite.
- Preserve lineage.
- Knowledge is additive.
- Servers curate knowledge.
- Clients execute missions and report observations.
- Every node has identity.
- Every heartbeat communicates state, not just presence.
- Capabilities are advertised, never assumed.
- Trust is explicit and revocable.
- Secrets never federate.
- Nodes remain useful while offline.
- Every successful mission can become a reusable knowledge artifact.
- Software updates preserve user data and migrate knowledge.

Node Doctrine
Nodes are workers, not merely devices.
Examples: Android, Windows, Linux, Raspberry Pi, Vehicles, Cameras, IoT, Robotics.

Mission Doctrine
Observe → Understand → Decide → Ask (if required) → Act → Verify → Learn

Knowledge Doctrine
Knowledge should be versioned, verified, searchable, signed, transportable, mergeable and preserved.

# Shared SWRLZ Board Components

Reserved for reusable, implementation-approved components shared by Keyboard, CLIENT integration, Launcher, and Widgets.

Planned areas:

- identity contracts;
- scoped credential models;
- protocol/version models;
- telemetry envelopes and redaction;
- design-system tokens;
- fonts and glyph metadata;
- local route and Truth Firewall interfaces.

Shared code must not create a second source of truth beside the canonical CLIENT and accepted contracts.

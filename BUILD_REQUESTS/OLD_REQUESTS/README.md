# Historical Build Requests

This directory preserves request contracts that are no longer consumed by the active APK router.

- `CORE_BUILD_002A.request` is the exact former multi-section `000_CURRENT.request` used for the verified CORE-BUILD-002A checkpoint.
- `BUILD_REQUESTS/SERVER_CONTRACT_CATCHUP_010D/` remains a retained staged evidence set. Its one-shot workflow is retired, and the router does not scan that directory.

Historical requests are lineage receipts, not executable current instructions.
